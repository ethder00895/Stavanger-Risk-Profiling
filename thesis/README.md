# Noroff University College - LaTeX for Bachelor  Project (BPR) Reports

This class is intended to be used for the production of  Bachelor  Project at Noroff University College for the 2024/25 academic year. This applies to the ACD, CSE and DFO degrees.


This class extends the standard report class.

## Usage
The sample main.tex provided a minimalist use of the nucthesis class.  

Users should be aware that they should remove a number of the guidance blocks (\guidence*) from the code once they have read them. These are there to provide some guidance about what should go in the sections.

See configuration.tex for some key elements thhat are required to be configured.


YMMV.
